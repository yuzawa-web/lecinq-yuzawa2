### 1. 写真に写っている方の掲載許可

`fv-photo.jpg` `fv-photo-sp.jpg`（1枚目の大きな写真）には、**利用者さんと職員さんが写っています。**

### 2. いまの状態は「お試し」です

検索結果に出ないよう、2か所で止めてあります。

- `index.html` の中の `<meta name="robots" content="noindex,nofollow">`
- `robots.txt` の `Disallow: /`

**本番として公開するときは、この2つを必ず外してください。**

### 3. images フォルダの9枚は「仮の画像」です

いただいた1枚の写真を切り出してぼかしたもので、**左上に小さく「仮」**と入っています。
仕上がりの雰囲気を見るためのものなので、**公開前に本物の写真に差し替えてください。**

## 写真を差し替えるとき

## 設計のきまり（さわるときの注意）

1. **見せ場は1枚目の一行だけ。** ページ内の見出しは、必ずこの一行より小さくする
2. **動くものは4つだけ。** それぞれ理由があります
   - 見せ場の一行が下から上がりながら濃くなる … 見せ場に視線を集めるため
   - ボタン・リンクの色が変わる … 「押せる場所」だと伝えるため
   - 画面下のバーが最後で隠れる … 同じボタンの二重表示を防ぐため
   - 食事の説明が濃くなる（動かない） … ①と区別するため、あえて動かさない
3. **スクロールで「現れる」演出は入れない**
4. ボタンの `id` と、採用リンクの `?utm_...` は**消さない**（押された回数を数えるため）
